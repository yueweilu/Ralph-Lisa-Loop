# S4.1 显式暂停与恢复

日期：2026-11-04。分支：`feat/herdr-s4-pause-resume`。

## 行为

- Herdr `pause` action 将独占控制请求写入插件状态目录；常驻协调器确认后持久化 `paused`，停止自动提示投递，仍继续维护 RLL 宿主租约。用户应等 action 返回 `paused` 后再在 Agent Pane 中人工输入。
- `resume` 仅在项目、会话、租约、绑定代次、两席 Agent/Pane，以及暂停时的 RLL 代次、回执、轮次、摘要均未改变时恢复。目标 Agent 尚在工作时返回 `AGENT_NOT_READY`，保持暂停，稍后可重试。
- 暂停期间若产生正式提交回执，协调器不投递；恢复时将其视为需要人工核对的状态，不自动补发。`stop` 可在暂停状态且无待交接回执时释放租约。`status` 现展示本地协调器阶段。
- CLI 的短暂 `HOST_BUSY` 宿主锁冲突留待下一次轮询，不把正常提交并发误报为永久故障。其他不一致仍进入 `needs_reconcile`。

## 验证与边界

临时项目与真实公开 CLI、伪 Herdr 的集成测试覆盖暂停确认、状态可见、忙碌恢复重试、继续 Ralph → Lisa → Ralph 交接、暂停期间提交无提示，以及恢复时状态变化停在待核对。插件测试 12/12 通过；远端 CI 结果在推送后核对。

本切片未在真实 Herdr Pane 中操作 Agent；当前 Codex 运行环境不带 `HERDR_ENV=1`，按本机 Herdr 控制规范没有从外部操作现有用户会话。真实 Herdr 下的暂停/恢复、服务重启恢复、人工提交后如何安全重接，以及无需逐轮人工确认的候选来源，仍需分别验收或开发。
